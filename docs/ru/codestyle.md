# Стиль кода

[HEID//R](../../README.md) · [Документация](README.md) · [English](../en/codestyle.md)

Главное правило одно: **код должен нормально читаться, если стереть из него все
комментарии до единого.** Комментарий объясняет, почему сделано именно так, и
никогда — что делает соседняя строка. Пишутся комментарии на простом
техническом английском.

## Форма

Функции держим короткими. Если внутри функции понадобился комментарий-заголовок,
отделяющий одну часть от другой, значит там просились две функции.

Всё, что пересекает границу модуля, ездит в дата-классах, а не в словарях: так
видно, что именно передаётся, и опечатка в имени поля обнаруживается сразу.

Типы проставляются везде. Docstring не пишем — вся проза живёт в `docs/`, и
дублировать её в коде незачем. Импорты только явные, без `from x import *` и без
файлов, которые ничего не делают, кроме переэкспорта чужих имён.

## Чего в этом коде быть не должно

Никаких метаклассов, дескрипторов и трюков с `__getattr__`. Наследования глубже
одного уровня тоже нет, и абстрактный базовый класс ради единственной реализации
не заводится.

Фабрик, строителей и реестров сверх тех четырёх, что уже есть, не появляется.
`**kwargs` не пробрасывается через слои: параметры называются по именам, иначе
через полгода никто не скажет, что туда можно положить.

Обработка ошибок пишется только для того, что действительно может случиться.
Внутренним гарантиям верим. Прослойки совместимости для удалённого кода не
оставляем.

## Имена

Имя говорит, чем вещь является, а не из чего она сделана.

```python
# нет
def proc(d, f=None): ...
mgr = ModuleManagerFactory().create()

# да
def draw_rite(config: Config) -> Rite: ...
```

## Ошибки, которые видит человек

Сообщение об ошибке состоит из трёх частей строго в этом порядке: что случилось,
почему это случилось и что теперь делать. Никаких кодов, трассировок и упрёков в
адрес пользователя.

```python
# нет
raise RuntimeError("SDR init failed (errno 19)")

# да
raise Unavailable(
    "No radio found. The RTL-SDR dongle is not plugged in. "
    "Connect it and run :checkhealth."
)
```

Весь текст, который человек может увидеть, лежит в `heidr/strings.py`. В коде
строк с сообщениями нет.

## Заимствованный код

Если фрагмент взят у кого-то, шапка оригинала остаётся в файле: автор, ссылка,
лицензия и одна строка о том, что именно позаимствовано.

```python
# Von Neumann debiasing and SHA-512 whitening.
# Adapted from rtl-entropy by Paul Warren, GPL-3.0.
# https://github.com/pwarren/rtl-entropy
```

Когда лицензия копировать не позволяет, пишем своё по опубликованному описанию и
честно это отмечаем: `# Method described in <link>; implementation is our own.`

## Комментарии

Комментарий появляется только там, где логика неочевидна из самого кода.
Разделительных баннеров, закомментированного кода и упоминаний инструментов,
плагинов или ассистентов в этом репозитории нет.

```python
# нет
# loop over modules
for module in modules:

# да
# Modules drawn recently are penalised, not banned: a repeat must stay possible
# or a coincidence would mean nothing.
weight = base / (penalty if name in recent else 1)
```

## Язык документации

Документация ведётся на двух языках, и требования к ним разные.

Английские файлы в `docs/en/` пишутся простым техническим английским: короткие
предложения, прямой порядок слов, никаких идиом и синонимов ради разнообразия.
Их будут читать люди, для которых английский неродной, и переводить машиной.

Русские файлы в `docs/ru/` пишутся живым литературным русским. Это связный текст,
а не подстрочник и не набор обрубленных пунктов: предложения полные, между
абзацами есть переходы, термин появляется тогда, когда без него не обойтись, и
поясняется при первом употреблении. Таблица уместна там, где данные
действительно табличные — список модулей, лицензии, сигнатуры, — но объяснение
устройства таблицей не заменяется.

Проверка простая: прочитайте абзац вслух. Если он звучит как перевод инструкции
к утюгу, его нужно переписать.

Файлы в `docs/en/` и `docs/ru/` соответствуют друг другу по именам и по смыслу.
Меняете один — меняйте второй в том же коммите.
