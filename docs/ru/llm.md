# Поставщики языковой модели

[HEID//R](../../README.md) · [Документация](README.md) · [English](../en/llm.md)

Толкованию может понадобиться модель, чтобы разобрать найденное. Какая именно
модель и где она запущена — это одна строка настроек.

## Договор

Поставщик — это класс с одним методом:

```python
def stream(self, messages: list[Message]) -> Iterator[str]
```

Он отдаёт текст по мере поступления. Никто не копит ответ целиком, поэтому
толкование появляется на экране слово за словом, а не одним куском в конце.

## Что есть в поставке

| `llm.provider` | С чем разговаривает | Особенности |
|---|---|---|
| `ollama` | локальный демон ollama | `POST /api/chat`, JSON построчно |
| `openai_compat` | всё, что понимает `/v1/chat/completions` | сервер llama.cpp, OpenAI и сервисы, скопировавшие его форму |
| `anthropic` | messages API от Anthropic | системная подсказка едет отдельным полем, а не сообщением |

Между сервером llama.cpp и облачным сервисом переключаются одинаково: правят
`base_url` и `model`.

## Настройки

```toml
[llm]
provider = "ollama"
model = "qwen3.5:9B"
base_url = "http://localhost:11434"
api_key_env = "HEIDR_LLM_KEY"
timeout = 120
max_tokens = 1024
think = false
```

| Ключ | По умолчанию | Зачем |
|---|---|---|
| `temperature` | 0.8 | Ответу нужнее разнообразие, чем точность |
| `top_p` | 0.9 | Обычный спутник температуры |
| `repeat_penalty` | 1.1 | Модель, читающая шум, склонна зацикливаться |
| `context_tokens` | 8192 | `num_ctx`. Слишком мало — и сервер молча обрежет материал |
| `max_tokens` | 400 | `num_predict`. Самый длинный ответ, которого стоит ждать |
| `keep_alive` | `10m` | Только для ollama. Модель на девять миллиардов параметров грузится шесть секунд и раньше перезагружалась перед каждым прогоном |
| `fragment_chars` | 1200 | Сколько найденного материала показать модели |

Ключ `think` читает только поставщик ollama. Рассуждающая модель, которой дали
стену случайных букв, способна потратить весь бюджет вывода на рассуждение и
закончить пустым ответом — на экран тогда попадёт материал и больше ничего. По
умолчанию стоит `false`, и модель отвечает сразу. Ставить `true` стоит только с
такой моделью и такой длиной контекста, которые это выдержат.

Раньше настройки не отправлялись вовсе и всё решали значения сервера по
умолчанию, включая окно контекста, в которое страница найденного не помещалась.
Сервису в форме OpenAI уходят `temperature`, `top_p` и `max_tokens` — больше в
его API ничего и нет; остальное принадлежит ollama.

Толкование, которое всем этим пользуется, — [pythia](modules/pythia.md).

`api_key_env` — это **имя переменной окружения**, а не ключ. Ключи никогда не
читаются из файла настроек и никогда в него не пишутся.

## Если поставщика не удалось собрать

Опечатка в названии поставщика или облачный сервис без ключа в окружении не
роняют прогон посередине. Возможность `llm` просто не выдаётся при проверке:
толкования, которым нужна модель, не попадают в выбор, а `:checkhealth`
показывает, чего не хватает. Программа продолжает работать теми толкованиями,
которым не нужно ничего.

## Как просят толкование

Про подсказку стоит записать две вещи, потому что обе однажды были сделаны
неправильно и это было видно по ответам.

**Просят истолковать, а не провести аудит.** Раньше в подсказке стояло:
«пользуйся только тем, что есть во фрагменте, не выдумывай». Получив стену
случайных байтов, честная модель отвечала, что во фрагменте нет пригодной
информации. Верно и бесполезно. Гадатель по внутренностям знает, что перед ним
внутренности. Теперь подсказка говорит, откуда взялся фрагмент и что он написан
ни для кого, и просит назвать одну-две конкретные вещи, которые в нём заметны, и
что они значат для вопроса. Говорить, что фрагмент случаен или что данных мало,
прямо запрещено.

**Просят отвечать на языке вопроса.** Русский вопрос возвращался с английским
ответом — вся подсказка написана по-английски, а модель идёт за тем, что читает.
Теперь вопрос повторяется последней строкой сообщения, и указание про язык
прицеплено к нему: модель следует за последним прочитанным.

Ответ приходит потоком обрывков в несколько символов, а толкование отдаёт
строки, поэтому `llm.base.lines` собирает их обратно. Без этого ответ выходил на
экран по слову на строку.

## Правило, которое старше всего перечисленного

**Модель истолковывает материал. Она никогда его не выбирает.** Толкование
передаёт модели найденное и отдаёт наружу то, что пришло в ответ. Оно не
спрашивает у модели, какую страницу открыть, какую частоту послушать и какую из
нескольких находок предпочесть. В ту секунду, когда выбирает модель, ответ
становится сочинённым, а не найденным, — и программа перестаёт быть тем, чем
себя называет.

## Зависимости

`requests`. Доступ по сети туда, куда указывает поставщик; для ollama и
llama.cpp это localhost.
