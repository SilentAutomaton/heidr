# Редактор настроек и список модулей

Две страницы, открываемые из интерфейса, чтобы не приходилось выходить из
программы ради правки конфига.

## `:modules`

Список всех зарегистрированных модулей: слот, имя и состояние.

| Состояние | Что значит |
|---|---|
| `ready` | Работает здесь и сейчас, участвует в жребии |
| `needs sdr, stt` | Не хватает перечисленного |
| `unavailable` | Собственная проверка модуля сказала «нет» |
| `off` | Выключен вами |

Отличать эти четыре важно. `needs sdr` означает «воткни донгл», а `off` —
«ты сам это выключил, я помню». Первое исправляется железом, второе — той же
клавишей `Enter`.

Навигация: `j` и `k` по списку, `Enter` переключает модуль. Выключенный модуль
перестаёт попадать в жребий немедленно, ждать перезапуска не нужно.

## `:settings`

Все настраиваемые параметры, кроме секций отдельных модулей: интерфейс, звук,
языковая модель, распознавание речи, обряд, журнал. У каждого — текущее значение
с учётом всех слоёв, а не то, что записано в файле.

`Enter` на строке открывает командную строку с уже подставленным
`:set ключ=значение`, остаётся только поменять хвост. Так меньше шансов опечататься
в имени ключа.

## `:set`

Работает и без списка. Значение приводится к типу по виду: `true` и `false`
становятся булевыми, целые и дробные — числами, остальное остаётся строкой.

```
:set audio.target_rms=0.2
:set ui.splash=false
:set modules.fm_voice.dwell_s=8
```

Изменения действуют сразу, включая громкость и параметры выравнивания.

## `:w`

Записывает настройки в `~/.config/heidr/config.toml`.

В файл попадает только то, что отличается от значений по умолчанию. Конфиг
остаётся коротким и читаемым, а не превращается в дамп всех параметров, среди
которых не найти собственных правок.

Без `:w` изменения живут до выхода из программы. Это сделано намеренно: покрутить
громкость на один сеанс — обычное дело, и незачем каждый раз переписывать файл.

## Настройки модулей

Секции `[modules.<имя>]` в списке не показываются: у каждого модуля свой набор, и
разумное место для их описания — документ самого модуля.

Менять их из интерфейса можно так же: `:set modules.sky.radius_nm=80`.
