# Установка

[HEID//R](../../README.md) · [Документация](README.md) · [English](../en/install.md)

Обязателен только Python 3.11 или новее. Всё остальное можно поставить потом
или не ставить совсем: без приёмника, микрофона и языковой модели программа
работает — просто часть источников не попадает в выбор.

Если не понимаете, чего не хватает, спросите саму программу:

```
heidr --self-check
```

Она напечатает по строке на каждую возможность и скажет, чего недостаёт.

## Linux

```
pip install -e '.[audio]'
heidr
```

Этого хватает, чтобы всё запустилось.

Дальше — по желанию.

**Радио.** Поставьте пакет `rtl-sdr`, он есть во всех дистрибутивах. Внутри
лежат программы `rtl_sdr`, `rtl_fm` и `rtl_power` — радиоисточники запускают их
сами. Ещё двум источникам нужны `rtl_433` и `dump1090`; это отдельные пакеты, и
ставить их стоит, только если эти два источника вам интересны.

**Распознавание речи.** Либо `pip install -e '.[vosk]'`, либо собранный
[whisper.cpp](https://github.com/ggml-org/whisper.cpp). Точная команда сборки
есть в [stt.md](stt.md), там же сказано, какую модель брать.

**Языковая модель.** Ollama или сервер llama.cpp на localhost. Без неё
обходятся пять толкований из шести — модель нужна только `pythia`.

## macOS

Ставится нативно, эмулировать ничего не нужно. Встроенного терминала хватает,
хотя iTerm2 и kitty рисуют брайлевские анимации заметно чище.

```
brew install rtl-sdr ollama
pip install -e '.[audio]'
```

`sounddevice` находит CoreAudio сам. whisper.cpp собирается так же, как на
Linux, и использует Accelerate — работает он быстрее, чем обещают цифры в
[stt.md](stt.md).

## Windows

Работает всё, кроме приёмника.

```
py -m pip install -e ".[audio]"
py -m heidr
```

Два условия. Терминал должен быть Windows Terminal, а не старая консоль: старая
не рисует ни блочные глифы, ни цвета. И запускать надо из оболочки, которая не
трогает управляющие последовательности, — PowerShell и cmd внутри Windows
Terminal обе подходят.

Что работает: интерфейс, анимации, звук через `sounddevice`, локальная модель
через сборку ollama под Windows, копирование по `y`. Пути вроде
`~/.config/heidr` сами превращаются в профиль пользователя. Каталога
`/etc/heidr` в Windows нет, и это не ошибка: этот слой просто пропускается.

Что не работает: приёмник RTL-SDR. Драйвера, с которым умеют разговаривать
программы `rtl_*`, под Windows нет. Обходной путь — WSL2 и
[usbipd-win](https://github.com/dorssel/usbipd-win), которая пробрасывает
USB-устройство в Linux:

```
winget install usbipd
usbipd list
usbipd bind --busid <идентификатор донгла>
usbipd attach --wsl --busid <идентификатор донгла>
```

Внутри WSL2 приёмник становится обычным линуксовым устройством, и дальше
действует инструкция для Linux без изменений.

## Один файл вместо установки

`heidr.spec` собирает один исполняемый файл, внутри которого лежит и Python, и
все зависимости. Три команды для сборки есть в README.

Внешние программы остаются внешними и в этом случае: `rtl_fm`, `whisper-cli` и
ollama ищутся в системе во время запуска, и если какой-то из них нет, пропадают
только те источники, которым он был нужен.

## Проверка

```
heidr --self-check
```

По строке на каждую возможность, и напротив каждой недостающей — что поставить.
Как читать этот отчёт, написано в [проверке](checkhealth.md).

Машина, на которой нет ничего, кроме Python, программу всё равно запустит:
цепочке `gematria//babel//iching` не нужны ни сеть, ни радио, ни модель.
