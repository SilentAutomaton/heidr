# Установка

Нужен Python 3.11 или новее. Всё остальное необязательно, и программа сама
скажет, чего не хватает: `heidr --self-check` печатает по строке на каждую
возможность.

## Linux

```
pip install -e '.[audio]'
heidr
```

Приёмник требует пакета `rtl-sdr`: в нём лежат `rtl_sdr`, `rtl_fm` и
`rtl_power`, которые радиомодули запускают как отдельные процессы. Пакеты
`rtl_433` и `dump1090` ставятся отдельно, и нужны они всего двум источникам.

Для распознавания речи — либо `pip install -e '.[vosk]'`, либо собранный
[whisper.cpp](https://github.com/ggml-org/whisper.cpp); точная команда сборки
есть в [stt.md](stt.md).

Для языковой модели — ollama или сервер llama.cpp на localhost. Ни то, ни другое
не обязательно: шести толкованиям модель не нужна вовсе.

## macOS

Ставится нативно. Ничего эмулировать не нужно, встроенного терминала хватает,
хотя iTerm2 и kitty рисуют брайлевские анимации заметно лучше.

```
brew install rtl-sdr ollama
pip install -e '.[audio]'
```

`sounddevice` находит CoreAudio сам. whisper.cpp собирается так же, как на
Linux, и использует Accelerate, поэтому работает быстрее, чем сказано в
[stt.md](stt.md).

## Windows

Нативно работает всё, кроме приёмника.

```
py -m pip install -e ".[audio]"
py -m heidr
```

Условий два. Нужен Windows Terminal, а не старый хост консоли: старый не рисует
ни блочные глифы, ни цвета. И запускать лучше из PowerShell или cmd внутри
Windows Terminal — они не трогают управляющие последовательности.

Работает: интерфейс, анимации, звук через `sounddevice`, локальная модель через
сборку ollama для Windows и копирование по `y`, которое Windows Terminal
понимает. Пути вида `~/.config/heidr` разворачиваются в профиль пользователя
сами. Каталога `/etc/heidr` там нет, и это не ошибка — общесистемный слой
настроек просто пропускается.

Не работает приёмник RTL-SDR: под Windows нет драйвера, с которым умеют
разговаривать программы `rtl_*`. Обходной путь — WSL2 и
[usbipd-win](https://github.com/dorssel/usbipd-win), которая пробрасывает USB
внутрь Linux:

```
winget install usbipd
usbipd list
usbipd bind --busid <идентификатор донгла>
usbipd attach --wsl --busid <идентификатор донгла>
```

Внутри WSL2 приёмник становится обычным устройством Linux, и дальше действует
инструкция для Linux без изменений.

## Один файл вместо установки

`heidr.spec` собирает единственный исполняемый файл, внутри которого лежат и
Python, и все зависимости. Три команды сборки есть в README. Внешние программы
остаются внешними и там: `rtl_fm`, `whisper-cli` и ollama ищутся на PATH во
время работы, а отсутствие любой из них лишь убирает те источники, которым она
нужна.

## Проверка

```
heidr --self-check
```

По строке на возможность, и для каждой недостающей сказано, что поставить. На
машине, где нет ничего, кроме Python, программа всё равно работает: цепочке
`gematria//babel//iching` не нужны ни сеть, ни радио, ни модель.
