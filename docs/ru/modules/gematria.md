# gematria — модуль вопроса

[HEID//R](../../../README.md) · [Документация](../README.md) · [Модули](../README.md#модули) · [English](../../en/modules/gematria.md)

## Что делает

Превращает вопрос в число, сложив значения его букв, и оставляет два самых
длинных слова как якоря.

## Откуда берутся данные

Из самого вопроса. Больше ниоткуда.

## Как обрабатывается

1. Текст приводится к нижнему регистру.
2. Каждая буква получает значение по своему месту в кириллическом или латинском
   алфавите. Всё остальное — цифры, знаки препинания, пробелы — не даёт ничего.
3. Сумма становится `key.seed`.
4. Два самых длинных слова становятся якорями, которые будет искать источник.

Один и тот же вопрос всегда даёт один и тот же ключ. Так и задумано:
разнообразие приходит из мира, а не из арифметики.

## Зависимости

Никаких. Только стандартная библиотека.

## Источники

Обычай считать буквы числами старше любой его реализации и никому не
принадлежит. Ничего не копировалось.
