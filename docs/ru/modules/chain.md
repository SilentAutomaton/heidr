# chain — модуль мира

## Что делает

Читает свежий блок биткойна: корень Меркла даёт числа, а сообщения, которые люди
заплатили вписать в этот блок, дают текст.

## Откуда берутся данные

Из двух адресов blockchain.info:

```
https://blockchain.info/latestblock
https://blockchain.info/rawblock/{hash}
```

Второй ответ тяжёлый — это целый блок со всеми транзакциями, — поэтому ожидание
по умолчанию щедрое.

## Как обрабатывается

Сначала запрашивается хэш последнего блока, затем сам блок. Дальше берётся
**корень Меркла, а не хэш блока**, и это принципиально. Растущая сложность
майнинга загоняет в хэш блока всё более длинную цепочку ведущих нулей, и энтропия
там убывает год от года. У корня Меркла такого смещения нет.

Корень разрезается на четыре куска по восемь символов, каждый читается как
шестнадцатеричное число — это числа материала.

Потом просматриваются выходы всех транзакций. Те, чей скрипт начинается с `6a`,
то есть с кода операции `OP_RETURN`, расшифровываются как UTF-8, из результата
выбрасывается всё непечатаемое, и уцелевшее становится текстом материала.

`OP_RETURN` — это место, куда люди вписывают в цепочку что-то нарочно: имена,
даты, служебные метки, шутки, эпитафии. За каждую такую запись кто-то заплатил
комиссию, и ни одна из них не была адресована вам.

## Настройки

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `timeout` | 15 | Сколько секунд ждать каждый запрос |
| `messages` | 5 | Сколько записей `OP_RETURN` оставить |

## Зависимости

`requests`. Доступ в сеть.
