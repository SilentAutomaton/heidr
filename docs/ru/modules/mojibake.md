# mojibake — источник

[HEID//R](../../../README.md) · [Документация](../README.md) · [Модули](../README.md#модули) · [English](../../en/modules/mojibake.md)

## Что делает

Читает случайные байты у ядра и смотрит на них через неверную кодировку,
оставляя то, что случайно сложилось в буквы.

## Откуда берутся данные

Из `os.urandom`, то есть из пула энтропии ядра. Ни сети, ни железа, ни файлов —
именно поэтому программа продолжает работать с выдернутым донглом и без сети.

## Как обрабатывается

1. `key.seed` выбирает одну кодировку из `cp1251`, `koi8-r`, `cp1252`,
   `shift_jis` и `cp866` — те же байты в другой раз прочитались бы иначе.
2. Четыре килобайта случайных байтов декодируются через неё, причём
   нераспознанные последовательности заменяются, а не выбрасываются.
3. Из результата оставляются цепочки в три буквы и длиннее, всё прочее
   отбрасывается.
4. Цепочки становятся текстом материала, их длины — его числами.

Никто здесь не притворяется, что эти цепочки — слова. Это формы, пережившие
неверное прочтение, и ради них модуль и написан.

## Настройки

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `encodings` | пять старых кодовых страниц | Набор, из которого выбирает `key.seed` |
| `bytes` | 4096 | Сколько случайных байтов рассматривать |

## Зависимости

Никаких. Только стандартная библиотека.

## Источники

открывал двоичный файл в текстовом редакторе. Ничего не копировалось.
