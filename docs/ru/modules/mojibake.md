# mojibake — источник

[HEID//R](../../../README.md) · [Документация](../README.md) · [Модули](../README.md#модули) · [English](../../en/modules/mojibake.md)

## Что делает

Берёт у ядра случайные байты и смотрит на них через заведомо неподходящую
кодировку, оставляя то, что случайно сложилось в буквы.

## Откуда берутся данные

Из `os.urandom`, то есть из пула энтропии ядра. Ни сети, ни железа, ни файлов.
Именно этот модуль позволяет программе работать, когда донгл не воткнут, а сети
нет.

## Как обрабатывается

Ключ выбирает одну кодировку из пяти — `cp1251`, `koi8-r`, `cp1252`, `shift_jis`
и `cp866`, — так что одни и те же байты в другом прогоне прочитались бы иначе.
Через неё расшифровываются четыре килобайта случайных данных, причём
нерасшифруемые последовательности заменяются, а не выбрасываются: пропуски тоже
часть картины.

Дальше остаются только цепочки из трёх и более букв подряд, всё прочее
отбрасывается. Эти цепочки становятся текстом материала, а их длины — его
числами.

Модуль не делает вид, что нашёл слова. Он находит формы, пережившие неправильное
чтение, и в этом весь смысл.

## Настройки

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `encodings` | пять старых кодовых страниц | Из чего выбирает ключ |
| `bytes` | 4096 | Сколько случайных данных рассматривать |

## Зависимости

Никаких. Только стандартная библиотека.

## Источники

Мысль читать шум через неподходящую кодовую страницу — общее место для всякого,
кто хоть раз открывал двоичный файл в текстовом редакторе. Ничего не
заимствовано.
