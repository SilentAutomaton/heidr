# Как добавить модуль

[HEID//R](../../README.md) · [Документация](README.md) · [English](../en/module-guide.md)

Модуль — это один файл, один декоратор и одна функция `run`, плюс документация и
обычно ни одного собственного теста. Видов четыре.

| Вид | Пакет | Сигнатура |
|---|---|---|
| Вопрос | `heidr/question/` | `run(ctx, question) -> Key` |
| Источник | `heidr/world/` | `run(ctx, key) -> Material` |
| Толкование | `heidr/reading/` | `run(ctx, question, material) -> Iterator[str]` |
| Анимация | `heidr/visuals/art/` | отрисовщик, который может подписаться на событие |

Тот же самый файл можно положить в `~/.config/heidr/modules/` — модуль попадёт в
выбор, не попав в репозиторий.

## Источник целиком

`heidr/world/quake.py`:

```python
import requests

from heidr.contracts import Key, Material
from heidr.registry import world

FEED = "https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_hour.geojson"


def available(ctx) -> bool:
    return ctx.has("net")


@world("quake", needs=("net",), visual="tremor")
def run(ctx, key: Key) -> Material:
    events = requests.get(FEED, timeout=10).json()["features"]
    if not events:
        return Material("", (), "usgs", {})

    event = events[key.seed % len(events)]
    place = event["properties"]["place"]
    magnitude = event["properties"]["mag"]
    lon, lat, depth = event["geometry"]["coordinates"]

    ctx.emit("stage", f"quake {place}")
    return Material(
        text=place,
        numbers=(int(magnitude * 10), int(depth)),
        source="usgs",
        extra={"lat": lat, "lon": lon},
    )
```

Это весь модуль. Что тут стоит знать:

- В `needs` пишутся известные имена возможностей: `net`, `sdr`, `stt`, `llm`,
  `audio`. Модуль, чьи потребности не закрыты, в выбор не попадает.
- `available()` — дешёвая проверка. Она не должна ни бросать исключений, ни
  надолго задумываться.
- Бросать исключения можно и нужно. Лента, которая не отвечает; ответ, который не
  разбирается; устройство, занятое кем-то ещё — бросьте, и прогон возьмёт на этот
  слот другой модуль вместо того, чтобы закончиться. Материал без текста и без
  чисел означает то же самое и обрабатывается так же.
- Толкование, весь смысл которого — промолчать, объявляет это само:
  `@reading("mute", silent=True)`. Без этого молчание примут за отсутствие
  ответа, и слот уступят другому.
- `visual="tremor"` — пожелание, а не требование. Если такой анимации нет или
  терминал её не тянет, вместо неё пойдёт фоновая.
- Всё, что попадает на экран, попадает туда через `ctx.emit`. Никаких `print`.
- В `ctx.settings` лежит секция `[modules.quake]` этого модуля, уже слитая с
  объявленными значениями по умолчанию.
- `ctx.levels` — это громкость, тишина и выравнивание самого интерфейса. Модуль,
  который проигрывает звук, передаёт их в `audio.Output`, а не вычитывает числа
  из настроек, иначе клавиши громкости не достанут до того, что играет.

## Настройки

Значения по умолчанию объявляются в декораторе, читаются из `ctx.settings`:

```python
@world("fm_voice", needs=("sdr", "stt"), defaults={"dwell_s": 4, "sweep": "random"})
def run(ctx, key):
    dwell = ctx.settings["dwell_s"]
```

В [редакторе настроек](settings-editor.md) они появятся сами, по строке на
каждую, с действующими значениями. Трогать `config.py` не нужно; открыть его
стоит ровно в одном случае — добавить строку в `CHOICES`, когда у настройки есть
фиксированный набор значений и переключать её надо клавишей `Enter`, а не
набирать руками.

## Толкование

Толкования отдают текст потоком, поэтому пишутся через `yield`:

```python
@reading("cutup")
def run(ctx, question: str, material: Material):
    for line in cut_up(material.text, ctx.settings["max_cut"]):
        yield line
```

Если толкование обращается к языковой модели, оно берёт её из `ctx.llm` и
пропускает токены наружу как есть. **Модель истолковывает материал; выбирать его
она не должна никогда.**

## Анимация

Анимация — это отрисовщик. Он объявляет самый бедный терминал, на котором ещё
жив, и может назвать событие, из которого его будут кормить:

```python
@animation("waterfall", glyphs="blocks", event="spectrum")
class BlockWaterfall(Painter): ...
```

`glyphs` — это одно из `braille`, `blocks`, `box`, `ascii`. Зарегистрируйте одно
и то же имя несколько раз с разными уровнями глифов, и программа возьмёт лучший
из тех, что терминал умеет.

Геометрию пересчитывайте из текущего размера на каждом кадре. Ширину нельзя
кэшировать нигде: терминал меняют в размере прямо во время съёма, и съём не
должен этого заметить.

## Прежде чем считать дело сделанным

1. `docs/en/modules/<имя>.md` и `docs/ru/modules/<имя>.md`, с пятью разделами:
   что делает, откуда берутся данные, как обрабатывается, зависимости,
   источники.
2. Появилась новая зависимость? Впишите её в таблицы в `README.md` и в
   `pyproject.toml` — дополнением, если модуль не из основных.
3. Что-то позаимствовали? Шапка в файле и строка в `docs/en/credits.md`.
4. `pytest` — набор про реестр уже покрывает ваш модуль. Отдельный тест пишите
   только на ту логику, которой он не видит.
5. Один коммит, одна строка: `add quake world module`.
