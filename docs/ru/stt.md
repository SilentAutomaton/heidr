# Распознавание речи

Распознавание нужно ровно для двух вещей: продиктовать вопрос вместо того чтобы
его набрать, и превратить пойманный эфир в текст. Микрофон используется только
для первого и больше нигде.

## Договор

Каждый поставщик — это один класс с двумя методами:

```python
def available(self) -> bool
def transcribe(self, blocks: Iterable[np.ndarray]) -> Iterator[Partial]
```

`Partial` несёт текст и признак того, окончательный он или нет. Поставщики,
умеющие сообщить слово до конца фразы, так и делают; остальные отдают только
готовые результаты.

## Что есть в поставке

| `stt.provider` | Какой | Особенности |
|---|---|---|
| `vosk` | по-настоящему потоковый | Слова появляются, пока вы ещё говорите. На шумных коротких волнах слабее, но для диктовки — то что нужно |
| `whisper_cpp` | окнами | Ничего не выдаёт, пока окно не закрылось, зато расшифровка заметно лучше. Это выбор для эфира |
| `api` | облачный | Форма запроса как у OpenAI, её повторили и другие службы |

`whisper_cpp` ищет на пути `whisper-cli`, `whisper-cpp` или `main`, если только
`stt.binary` не указывает конкретный, и требует `stt.model_path` с файлом модели.
`vosk` требует `stt.model_path` с распакованным каталогом модели.

## Настройки

```toml
[stt]
provider = "vosk"
model_path = ""             # каталог для vosk, файл .bin для whisper.cpp
api_key_env = "HEIDR_STT_KEY"
window_s = 30               # длина окна whisper.cpp
language = "auto"
threads = 0                 # 0 — пусть whisper.cpp решает сам
```

Как и везде, `api_key_env` — это имя переменной окружения, а не сам ключ.

## Если поставщика использовать нельзя

Отсутствие модели, программы или ключа выясняется при опросе системы, а не
посреди обряда. Возможность `stt` снимается, голосовой ввод честно об этом
сообщает, радиомодули, которым нужна расшифровка, выходят из жребия, а всё
остальное продолжает работать.

## Почему whisper.cpp собран именно так

Сборка идёт только под процессор, с `-march=native`, на закреплённой версии и
совсем без CUDA. Это сознательно не самый быстрый из доступных на этой машине
вариантов.

Размен такой: скорость меняется на неломкость. Обновление драйвера, смена версии
CUDA или переустановка ollama на эту сборку не влияют никак, а оракул, переставший
работать после обновления системы, — уже не оракул.

## Зависимости

`numpy`. Пакет `vosk` для соответствующего поставщика, ставится как дополнение
`vosk`. Собранный бинарник `whisper.cpp` и файл модели для второго. `requests`
для облачной службы.
