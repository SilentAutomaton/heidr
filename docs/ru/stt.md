# Распознавание речи

[HEID//R](../../README.md) · [Документация](README.md) · [English](../en/stt.md)

Распознавание речи нужно ровно для двух вещей: продиктовать вопрос вместо того,
чтобы набрать его, и превратить пойманный эфир в текст. Микрофон участвует
только в первом.

## Договор

Поставщик — это класс с двумя методами:

```python
def available(self) -> bool
def transcribe(self, blocks: Iterable[np.ndarray]) -> Iterator[Partial]
```

`Partial` несёт текст и признак того, окончательный он или нет. Кто умеет
называть слово до конца фразы — называет; кто не умеет, отдаёт только
законченное.

## Что есть в поставке

| `stt.provider` | Как работает | Особенности |
|---|---|---|
| `vosk` | потоком | Слова появляются, пока вы ещё говорите. На шумных коротких волнах слабее, но для диктовки подходит лучше всего |
| `whisper_cpp` | окнами | До конца окна не выдаёт ничего, зато расшифровка заметно лучше. Это выбор для эфира |
| `api` | облачный | Форма транскрипции OpenAI, которую скопировали и остальные |

`whisper_cpp` ищет в системе `whisper-cli`, `whisper-cpp` или `main`, если только
`stt.binary` не указывает конкретный файл, и требует, чтобы `stt.model_path`
указывал на модель `.bin`. `vosk` требует, чтобы `stt.model_path` указывал на
распакованный каталог модели.

## Настройки

```toml
[stt]
provider = "vosk"
model_path = ""             # каталог для vosk, файл .bin для whisper.cpp
api_key_env = "HEIDR_STT_KEY"
window_s = 30               # длина окна whisper.cpp
language = "auto"
threads = 0                 # 0 — пусть whisper.cpp решает сам
```

Как и везде, `api_key_env` — это имя переменной окружения, а не сам ключ.

## Какая модель нужна для эфира

Для диктовки годится почти что угодно: вы говорите близко к микрофону, разборчиво
и в тихой комнате.

С эфиром всё наоборот, и размер модели там виден сразу. Слушают
[fm_voice](modules/fm_voice.md), [sw_voice](modules/sw_voice.md) и
[mw_voice](modules/mw_voice.md). На коротком шумном отрывке `small` выдаёт
примерно половину настоящих слов и половину собственных выдумок — правдоподобный
русский, которого в эфире не было. `medium` заметно лучше, `large-v3-turbo` ещё
лучше и при этом примерно такой же по скорости, как `medium`, за счёт
облегчённого декодера.

Длинная задержка на станции помогает не меньше, чем большая модель. Пятнадцать —
двадцать секунд на одной частоте дают модели достаточно контекста, чтобы
собраться; пять секунд — нет.

Считать ли выдумку недостатком, зависит от модуля. Для `fm_voice` — да, там есть
чистая речь, которую можно расслышать. Для `sw_voice` выдумка и есть смысл: об
этом написано в документе самого модуля.

## Если поставщика использовать нельзя

Отсутствие модели, отсутствие исполняемого файла или отсутствие ключа
проверяются при опросе возможностей, а не посреди прогона. Возможность `stt` не
выдаётся, голосовой ввод об этом говорит, радиоисточники, которым нужна
расшифровка, выпадают из выбора, а всё остальное продолжает работать.

## Почему whisper.cpp собран именно так

Сборка только под процессор, с `-march=native`, из закреплённой версии и вовсе
без CUDA. Это намеренно не самая быстрая конфигурация из возможных на этой
машине.

Обмен такой: скорость меняется на живучесть. Обновление драйвера, смена версии
CUDA или переустановка ollama не могут её сломать, а программа, переставшая
работать после обновления системы, хуже медленной.

## Как это собирается

```
git clone --depth 1 --branch b4938 https://github.com/ggml-org/whisper.cpp
cd whisper.cpp
cmake -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF \
      -DGGML_NATIVE=ON -DGGML_CUDA=OFF -DGGML_VULKAN=OFF -DGGML_BLAS=OFF \
      -DWHISPER_BUILD_TESTS=OFF -DWHISPER_BUILD_SERVER=OFF
cmake --build build -j"$(nproc)" --target whisper-cli
```

`BUILD_SHARED_LIBS=OFF` здесь не менее важен, чем всё остальное: на выходе
получается исполняемый файл на три мегабайта, который ничего своего не
подгружает. Его можно скопировать в `/usr/local/bin` и забыть о нём.

Дальше нужна модель и `stt.model_path`, который на неё указывает:

```
curl -L -o ggml-large-v3-turbo-q5_0.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
```

### Сколько это стоит

Замерено на шестиядерном i7-9750H с `ggml-large-v3-turbo-q5_0`, на одиннадцати
секундах чистой речи:

| | Секунд |
|---|---|
| `-l en`, шесть потоков | 26 |
| `-l auto`, шесть потоков | 55 |
| `-l en`, двенадцать потоков | 26 |

Отсюда два вывода. Двенадцать потоков на шести физических ядрах не дают ничего,
поэтому `stt.threads = 6`. И `language = "auto"` стоит второго прохода кодера —
это плата за то, чтобы иностранную станцию не расшифровали не на том языке. Для
эфира платить стоит, и именно поэтому тридцатисекундное окно занимает чуть
больше минуты.

`requests`.
